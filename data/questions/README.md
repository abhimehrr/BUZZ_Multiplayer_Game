# Question bank credits

BUZZ includes 1,000 multiple-choice questions in these JSON files. Most are adapted from the community-contributed **OpenTriviaQA** dataset by uberspot and its contributors: <https://github.com/uberspot/OpenTriviaQA>.

The adapted question-bank content is licensed under **Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0)**: <https://creativecommons.org/licenses/by-sa/4.0/>. Attribution: OpenTriviaQA contributors, “OpenTriviaQA,” https://github.com/uberspot/OpenTriviaQA, CC BY-SA 4.0.

Changes made for BUZZ: entries were selected from source category files, converted to the BUZZ JSON schema, assigned to the app's categories, screened for malformed or clearly time-sensitive/negative questions, and had their answer choices shuffled to balance correct-answer positions. The original 27 BUZZ starter questions remain in the bank.
